## Proyectos destacados

### [Unified Data Insights Platform](https://github.com/pamionj/unified-data-insights-platform)

**Plataforma de ingeniería de datos implementada en producción en Déficit Cero.**

- Consolida más de 48.000 registros provenientes de múltiples fuentes de datos.
- Implementa procesos de validación, normalización, deduplicación y conciliación de identidades.
- Incorpora mecanismos de trazabilidad, gobernanza de datos y auditoría de ejecuciones mediante SQLite.
- Proporciona dashboards interactivos con Streamlit y Plotly, además de automatizar reportes operacionales mediante integración con Google Sheets.

**Tecnologías:** Python, pandas, SQLite, Streamlit, Plotly, ETL.

### [AI Commercial Agent](https://github.com/pamionj/ai-commercial-agent)

**Sistema backend de inteligencia artificial aplicada a la automatización de procesos comerciales.**

- Integra modelos de inteligencia artificial para generar y procesar respuestas.
- Automatiza tareas repetitivas de interacción con usuarios e ingreso de datos.
- Estructura información comercial para facilitar su seguimiento y trazabilidad.
- Incorpora técnicas de recuperación de información mediante arquitecturas RAG.

**Tecnologías:** Python, FastAPI, LLMs, RAG, APIs REST.

### [User Management API](https://github.com/pamionj/user-management-api)

**API REST desarrollada en Java para la gestión de usuarios.**

- Implementa una arquitectura en capas para separar las responsabilidades de la aplicación.
- Incorpora operaciones CRUD, validación de datos y manejo centralizado de excepciones.
- Utiliza PostgreSQL para la persistencia de información.

**Tecnologías:** Java, Spring Boot, Spring Data JPA, PostgreSQL, APIs REST.
